# التداول الذكي PRO

إعادة بناء نظيفة بخادم Flask وواجهة عربية RTL خفيفة.

## التشغيل
`pip install -r requirements.txt`
`python app.py`

## مصادر البيانات
- Binance Spot وFutures: واجهات عامة لا تحتاج مفاتيح API.
- بقية الأسواق تبقى غير مفعّلة حتى إضافة مزود حقيقي. لا توجد أسعار افتراضية.

## API
- `/health` و`/api/health`
- `/api/markets`
- `/api/market/spot?timeframe=15m`
- `/api/market/futures?timeframe=1h`
- `/api/trades`

## الاستراتيجية
توافق اتجاه EMA20/EMA50 على الإطار المحدد و4 ساعات واليومي، مع RSI14، واتجاه السوق العام. مستويات الدخول والوقف والأهداف من ATR14 بنسبة مخاطرة/عائد 1R و2R و3R. درجة الجودة ليست احتمال ربح أو نسبة نجاح.

## تتبع الصفقات
تُحفظ الإشارات في SQLite وتُحدّث حالة TP1 وTP2 وTP3 وSL عند تحديث السوق. ثبّت وحدة تخزين دائمة في Northflank على `/data` حتى تبقى السجلات بعد إعادة النشر. لا يتم تنفيذ أوامر تداول آلية.

## النشر
المنفذ 8080، أمر التشغيل عبر Gunicorn مضمّن في Dockerfile.

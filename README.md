# التداول الذكي PRO

منصة عربية RTL لمراقبة الأسواق وتحليل الفرص الفنية، بواجهة داكنة متجاوبة ومصادر بيانات عامة.

## التشغيل
`pip install -r requirements.txt`
`python app.py`

## الأسواق ومصادر البيانات
- Binance Spot وFutures: واجهات عامة مباشرة لا تحتاج مفاتيح API.
- Binance Alpha: واجهات Binance العامة لقائمة الرموز ومعلومات أزواج USDT والشموع؛ لا تحتاج مفاتيح API.
- Binance Alpha مفعّل عبر واجهات Binance العامة، لكن قد يتوقف إذا رفض المصدر الطلبات.
- الأسهم السعودية والأمريكية والعقود الأمريكية والفوركس والذهب: لا يوجد لها مزود بيانات مربوط حاليًا، لذلك لا يمكنها إطلاق صفقات قبل إضافة مصدر موثوق لكل سوق.

## لوحة المنصة
- اتجاه السوق محسوب من عدد الأصول الصاعدة والهابطة والمحايدة خلال 24 ساعة.
- عرض أكثر ثلاثة أصول صعودًا وثلاثة هبوطًا من قائمة الأصول المؤهلة للسيولة.
- أفضل ثلاث فرص فنية من فحص ثابت على 15 دقيقة، دون أزرار لتغيير الأطر.
- عرض الدخول والأهداف الثلاثة والوقف ومؤشرات المخاطرة وجودة الشروط.
- سجل الصفقات المفتوحة والصفقات المغلقة.
- تحديث تلقائي كل 30 ثانية، مع منع تداخل الطلبات ومهلة اتصال.
- تصميم RTL داكن متجاوب للجوال وسطح المكتب.

## API
- `/health` و`/api/health`
- `/api/markets`
- `/api/market/spot`
- `/api/market/futures`
- `/api/market/alpha`
- `/api/trades?market=spot`

## الاستراتيجية
تحليل ثابت على 15 دقيقة باستخدام EMA20/EMA50 وRSI14 واتجاه السوق العام. يفحص النظام حتى 20 مرشحًا بدلًا من 10، دون اشتراط توافق أطر إضافية. مستويات الدخول والوقف والأهداف من ATR14 بنسبة مخاطرة/عائد 1R و2R و3R. درجة الجودة ليست احتمال ربح أو نسبة نجاح.

## تتبع الصفقات
تُحفظ الصفقات في SQLite وتُحدّث حالة TP1 وTP2 وTP3 وSL عند تحديث بيانات السوق. ثبّت وحدة تخزين دائمة في Northflank على `/data` حتى تبقى السجلات بعد إعادة النشر. لا يتم تنفيذ أوامر تداول آلية.

## النشر والاختبارات
المنفذ 8080، أمر التشغيل عبر Gunicorn مضمّن في Dockerfile. فحوص CI تشمل compileall وNode syntax check وpytest.

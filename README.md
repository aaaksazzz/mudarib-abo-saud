# مضارب أبو سعود

منصة تحليل أسواق بواجهة عربية.

## التشغيل
- Python 3.11+
- `pip install -r requirements.txt`
- `python server.py`

## Northflank
استخدم أمر التشغيل الموجود في Procfile، واضبط PORT تلقائياً من المنصة.
ضع SECRET_KEY وADMIN_PASSWORD وعناوين الدفع كـ Secrets.

## الأسواق
Crypto / Spot / Futures / Saudi / US Market / Forex & Gold.

> التحليلات آلية وليست ضماناً للربح أو توصية استثمارية.

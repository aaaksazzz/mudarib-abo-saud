# التداول الذكي PRO — إعادة بناء مستقلة

نسخة واجهة جديدة من الصفر مع FastAPI وواجهة عربية RTL متجاوبة.

## التشغيل
- Python 3.12+
- `pip install -r requirements.txt`
- `uvicorn app:app --host 0.0.0.0 --port 8080`

## المسارات
- `/` الواجهة الرئيسية
- `/health` فحص صحة الخدمة
- `/api/health` فحص API
- `/api/market/spot` بيانات Binance Spot العامة
- `/api/market/futures` بيانات Binance Futures العامة

## حدود النسخة
الأسعار العامة فقط متاحة حاليًا للسبوت والفيوتشر. لم يتم ربط مزودي بيانات الأسهم والسوق السعودي والفوركس، ولم يتم تفعيل الحسابات أو الإدارة أو نشر الأخبار أو توليد صفقات. لا تعرض الواجهة توصيات أو نتائج تداول مختلقة.

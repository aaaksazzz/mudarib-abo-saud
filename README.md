# SMART TRADING PRO

منصة مستقلة لمراقبة الأسواق، قياس اتجاهها، تحليل فرص التداول، ومتابعة الصفقات. الواجهة عربية RTL ومتوافقة مع الجوال، ولا تتطلب تسجيل دخول أو اشتراكاً لتصفح الأسواق.

## نطاق المنصة
- Binance Spot وUSD-M Futures وCOIN-M Futures وBinance Alpha عبر واجهات عامة.
- الفوركس والذهب عبر مصدر BiQuote العام، مع فحص حداثة الأسعار والشموع.
- السوق السعودي والأسهم الأمريكية: موصل Yahoo اختياري لقوائم رموز محددة فقط. لا يدّعي تغطية كل السوق، ولا يُفعّل افتراضياً.
- العقود الأمريكية: غير مفعّلة لعدم وجود مزود موثوق ومتكامل؛ لا تعرض المنصة بيانات أو صفقات مختلقة لهذا القسم.
- لكل سوق صفحة وبيانات مستقلة؛ لا تخلط نتائج سوق بآخر.

## التحليل والصفقات
- اتجاه السوق العام يُحسب من عدد الأصول الصاعدة والهابطة والمحايدة.
- ترتيب الأصول السريعة يعتمد على الزخم ونطاق الحركة والسيولة المتاحة؛ الدرجة ترتيب فحص وليست احتمال ربح.
- محرك الدخول يستخدم شموع 15 دقيقة المكتملة، وبنية الاتجاه، وسحب السيولة أو الامتصاص، والحجم النسبي. دفتر أوامر Binance تأكيد إضافي عند توفره فقط.
- بطاقة الصفقة تتضمن BUY/SELL والدخول ووقف الخسارة وTP1/TP2/TP3 وإطار التحليل ودرجة جودة الشروط.
- تُحفظ الصفقات في SQLite وتُحدّث حالات الأهداف والوقف. ثبّت وحدة تخزين دائمة على `/data` في Northflank.
- لا يوجد تنفيذ تداول آلي، ولا ربط بحساب Binance الخاص بالمستخدم، ولا حاجة إلى مفتاح OpenAI أو Binance API.

## الاستقرار
- دفعة الفحص: 20 أصلاً (10 أولوية + 10 بالتناوب).
- عمليتا تحليل متزامنتان، وعامل Gunicorn واحد مع أربع خيوط لتناسب موارد الخدمة الصغيرة.
- التخزين المؤقت يمنع تكرار طلبات البيانات، وقفل مستقل يمنع تداخل فحص السوق نفسه.
- لا يتم تقديم لقطة قديمة على أنها بيانات مباشرة؛ حالة قدم البيانات تظهر بوضوح عند تعذر المصدر.

## التشغيل المحلي
```bash
pip install -r requirements.txt
python app.py
```

المنفذ الافتراضي 8080.

## واجهات الخدمة
- `/health` و`/api/health`
- `/api/markets` و`/api/providers`
- `/api/overview`
- `/api/market/{market}`
- `/api/trades?market=spot`

## الاختبارات
```bash
python -m compileall -q app.py
node --check static/app.js
pytest -q
```

## حدود مهمة
درجة الجودة ليست نسبة نجاح. لا تعتبر أي استراتيجية مربحة قبل اختبار تاريخي حقيقي خارج العينة، مع الرسوم والانزلاق والتمويل. تغطية السوق مرتبطة بتوفر مزود بيانات موثوق وحداثة بياناته.

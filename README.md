# التداول الذكي PRO

واجهة عربية RTL لمتابعة الأسواق ورصد فرص التداول، مبنية باستخدام FastAPI وواجهة HTML/CSS/JavaScript متجاوبة.

## التشغيل المحلي

- Python 3.12+
- تثبيت الاعتماديات: `pip install -r requirements.txt`
- تشغيل الخدمة: `uvicorn app:app --host 0.0.0.0 --port 8080`

## الصفحات والواجهات

- `/` الصفحة الرئيسية.
- `/analysis/{slug}` صفحات مستقلة لمناهج التحليل.
- `/health` و`/api/health` فحص الخدمة.
- `/api/market/spot` و`/api/market/futures` أسعار Binance العامة.
- `/api/market/us`, `/api/market/saudi`, `/api/market/contracts`, `/api/market/forex` أسعار عامة من Yahoo Finance وقد تكون متأخرة.
- `/api/signals/{market}` محرك تحليل فني متعدد العوامل لكل الأسواق المدعومة، مع توافق فريمات ومستويات ATR/بنية سعرية.
- `/api/results` سجل الإشارات التي تابعتها الخدمة.
- `/api/news` عناوين أخبار مجمعة.
- `/api/blog` مقالات المدونة.
- `/api/admin/*` وظائف الإدارة المحمية بمصادقة HTTP Basic.
- `/robots.txt` و`/sitemap.xml` لخريطة الموقع، مع روابط canonical ووصف بحث مستقل لكل قسم.

## حدود مهمة

- Binance Alpha غير مربوط كمصدر بيانات في هذه النسخة؛ يعرض الموقع حالة عدم التوفر بدل اختلاق الأسعار.
- أسعار Yahoo Finance عامة وقد تكون متأخرة، وليست بيانات تنفيذ لحظي.
- محرك الفرص `trend_4h_1d_rank_15m_v2` يعمل محليًا دون مفتاح OpenAI أو مزود توصيات خارجي. اتجاه 4 ساعات واليومي يحددان الشراء أو البيع، ولا تُقبل الفرصة عند اختلافهما؛ تغير 15 دقيقة يُستخدم للترتيب فقط.
- تُحسب مستويات الدخول ووقف الخسارة والأهداف من ATR وبنية السعر على شموع 15 دقيقة، مع حد أقصى للمخاطرة. المحرك قواعد تحليل فني وليس نموذج ذكاء اصطناعي؛ لذلك `generated_by_ai=false` و`ai_reviewed=false`. درجة قوة الاتجاه ليست احتمال ربح ولا ضمانًا.
- للحفاظ على استقرار الخادم الصغير، يفحص كل تشغيل دفعة محدودة من 8–12 أصلًا، ويدوّر الدفعات تلقائيًا عبر قائمة السوق في عمليات الفحص المتتابعة. قد يستغرق المرور على كامل السوق عدة دورات بحسب عدد الأصول.
- سجل النتائج يحتفظ بالإشارات خلال آخر 24 ساعة فقط؛ ويُضبط `DATA_DIR` على تخزين دائم إذا أردت الاحتفاظ بالسجل بين عمليات إعادة إنشاء الحاوية.
- صفحات الموقع العامة وملفات SEO مفتوحة افتراضيًا حتى تستطيع محركات البحث فهرستها. إذا احتجت بوابة PIN مؤقتة، اضبط `SITE_PASSWORD_GATE=true` و`SITE_PASSWORD`؛ لا يوجد رمز افتراضي آمن.
- تسجيل حسابات العملاء غير مفعّل في هذه النسخة. واجهة الحساب لا تدّعي وجود تسجيل عضوية أو اشتراكات فعلية.
- لوحة الإدارة تتطلب ضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD` كمتغيرات بيئة؛ تبقى الإدارة مقفلة إذا لم تُضبطا. واجهات الإدارة غير معروضة في قائمة المستخدم العادي.

## النشر

اضبط المنصة على المنفذ `8080`، وتأكد من وجود تخزين دائم لمسار `DATA_DIR` إذا أردت الاحتفاظ بسجل النتائج والمقالات بين عمليات إعادة النشر.

## فحوصات الجودة

- تُشغّل GitHub Actions اختبارات دخان عند كل دفع إلى `main` أو فتح طلب دمج.
- الاختبارات تتحقق من فحص الصحة، والصفحة الرئيسية، والروابط الأساسية وبيانات SEO لكل قسم، وخريطة الموقع، وانتهاء صلاحية النتائج بعد 24 ساعة.
- التشغيل المحلي للاختبارات: `pip install pytest "httpx<0.28"` ثم `pytest -q`.
